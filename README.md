# Sistema de Tutoría

Aplicación web desarrollada en equipo con Vue 3 y Vite.

## Inicio rápido

```bash
npm install
npm run dev
```

## Trabajo por vistas

- Cada vista nueva debe agregarse como un componente dentro de `src/components`.
- Crear una rama por vista, por ejemplo: `feature/vista-login`.
- Probar la vista localmente antes de abrir el pull request hacia `main`.
- Evitar modificar componentes de otros integrantes sin coordinarlo previamente.

## Estructura inicial

- `src/components`: vistas y componentes reutilizables.
- `src/App.vue`: composición principal de la aplicación.
- `src/main.js`: punto de entrada.
- `public`: recursos estáticos.
